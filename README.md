# Music Studio Landing Page - Vibrant Audio

**Role:** Frontend Developer  
**Date:** 2024  
**Live Website:** [See the live website](https://www.ariane-dev.music-studio.adwstudium.com/)

## Project Overview:

The **Vibrant Audio Music Studio Landing Page** is a dynamic and interactive page designed for a music studio seeking to establish a strong online presence. Developed using **React**, this landing page fetches **real-time music data** from the **Last.fm API**, showcasing trending artists, albums, and top charts. The dynamic content keeps the site engaging and relevant, providing users with up-to-date information about the latest music trends.

To further enhance the user experience, **GSAP** animations were integrated to provide smooth, scroll-triggered effects, making navigation intuitive and visually appealing.

## Technologies Used:
- **Frontend Framework:** React
- **API Fetching:** Last.fm API for real-time music data
- **Animations:** GSAP for smooth, scroll-triggered effects
- **CSS:** Styling for responsive and modern design
- **JavaScript:** Enhancing interactivity and functionality
- **Responsive Design:** Ensures optimized display across both desktop and mobile devices

---

## Features:
- **React Development:**  
  Built using **React**, enabling a dynamic and interactive user interface that makes the site feel modern and engaging.

- **API Fetching (Last.fm API):**  
  Integrated the **Last.fm API** to display trending artists, albums, and top charts in real-time, ensuring the site’s content remains fresh and up-to-date.

- **GSAP Animations:**  
  Added smooth, scroll-triggered animations using **GSAP** to enhance navigation and improve overall user experience by creating a more fluid browsing experience.

- **Responsive Design:**  
  Ensured the site is fully responsive, optimizing it for both **mobile** and **desktop** devices to guarantee a seamless experience for all users.

- **Branding and Visual Identity:**  
  Focused on promoting the studio’s services and brand identity with clear, visually engaging elements.

---

## UX/UI:

- **Modern, Clean Design:**  
  A minimalist design to emphasize the content and provide an uncluttered viewing experience.

- **Dynamic Content:**  
  The integration of **real-time music data** makes the site continuously fresh and relevant, encouraging users to explore trending music.

- **Scroll-Triggered Animations:**  
  Using **GSAP**, the page incorporates smooth animations that trigger when users scroll, adding a polished feel to the user interface.
